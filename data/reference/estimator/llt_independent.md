## Independent derivation

[MIT Fluids Lecture 9](https://web.mit.edu/16.unified/www/SPRING/fluids/Spring2008/LectureNotes/f09.pdf),
pages 1–3, gives the Fourier circulation/induced angle, CL=pi*AR*A1,
CDi=pi*AR*sum(n*A_n^2), and efficiency=A1^2/sum(n*A_n^2).
Combining with the section law gives the matrix documented in lifting_line.md.
The same collocation discretization is used, with an independent algorithm:
Python standard-library binary64 arithmetic, Gaussian elimination with partial
pivoting and back substitution; no nalgebra, Rust solver calls or production
Fourier coefficients. This is an independent implementation of the same theory,
not an independent experimental validation of lifting line.

Inputs: span=12 m, chord=2 m, AR=6, alpha=.08 rad, alpha_L0=-.02 rad,
zero twist, section slope=2*pi/rad. Hence rhs=.1 and 4b/(a0*c)=12/pi.
An initial exploratory transcription used 24/pi; it was corrected before
freezing any expectation. The expected constants remain the owner's values.

For N odd terms, n=1,3,...,2N-1 and theta_i=(i+1)*pi/(2N).
The augmented matrix is `sin(n*theta)*(12/pi+n/sin(theta)) | .1`.
At column k choose the remaining row with largest abs(pivot), eliminate lower
entries, then back-substitute. Compute CL/CDi/e from the solved A values using
the lecture formulas above. Reproduction:

| N | Independent Python CL | Independent Python CDi | Independent Python e |
|---|---|---|---|
| 4 | 0.45272804019142754 | 0.011377841172797585 | 0.9556828610222085 |
| 128 | 0.4530424985369394 | 0.01141453139791682 | 0.9539347671769475 |

These match the owner's printed constants within about 5e-16. The test uses
those printed constants, not this recomputation as a runtime oracle.

## Tolerance and fault evidence

Absolute tolerance is 2e-12 for each dimensionless quantity, unchanged after
the first run. It covers printed rounding (at most 5e-16) and a numerical
roundoff guard 64*128*epsilon_binary64 = 1.818989403546e-12. That guard is a
declared numerical policy, not a rigorous condition-number/forward-error bound.
The maximum relative allowance is below 1.8e-10 at the smallest CDi, far
tighter than 10%. Every tolerance/count/input is ledgered.
