# Standard-atmosphere reference for T3

Source: NOAA/NASA/USAF, *U.S. Standard Atmosphere, 1976*, NOAA-S/T 76-1562,
NASA-TM-X-74335, [NTRS 19770009539](https://ntrs.nasa.gov/citations/19770009539).
The original scanned tables were visually checked on 2026-11-13. The report is
a U.S. Government work; NTRS permits public use. No aircraft data are used here.

(the report's Table 1, printed page 2). These are transcribed reference values,
not values generated by our implementation.

Every temperature, pressure, density and sound-speed digit in these five rows
was rechecked visually against the scanned PDF pages on 2026-11-13. No
transcription changes were needed: in particular, page 54 prints `5.4019 * 10^2 mb`.

The owner authorized **relative tolerance 5e-5** for pressure and density on
2026-11-13. Relative error means `abs(equation - printed) / abs(printed)`.
Temperature retains an absolute tolerance of 0.0005 K and sound speed 0.005 m/s.
These are numerical table comparisons, not D9's real-aircraft validation limits.

At H = 5000 m, equation (33a) gives **54019.912103762079 Pa**, versus the printed
**54019 Pa**: signed difference **+0.912103762079 Pa**, absolute difference
**0.912103762079 Pa**, relative difference **1.688486944e-5**. The previous
0.5 Pa limit failed. The chosen 5e-5 accommodates this recorded discrepancy and
the other rows, while the sensitivity checks below reject substantial mistakes.
No model constant was fitted to the printed checkpoint.

The hypothesis that rounded constants caused the discrepancy was tested with
decimal arithmetic at 50-digit precision, treating the listed `R* = 8314.32`,
`M0 = 28.9644`, `g0 = 9.80665`, `T0 = 288.15`, `L = -0.0065` and `P0 = 101325`
as exact decimal inputs. Computing
`P0 * exp((-g0 / ((R*/M0)*L)) * ln((T0+L*5000)/T0))` gives
`54019.912103762073475131117609403624433607022421021 Pa`.
It differs from the Rust binary64 result by about `6.5e-12 Pa`, and leaves the
printed-table discrepancy intact. The implementation already used R*/M0 without
rounding. A tabulation/printing issue or an undocumented calculation difference
is a **hypothesis**, not an established cause; no cause was verified.

## Constants and equations

The same report supplies g0 = 9.80665 m/s^2, sea-level pressure 101325 Pa,
sea-level temperature 288.15 K and gamma = 1.40 (Table 2, page 2),
effective radius 6356766 m (page 4), R* = 8314.32 J/(kmol K) (page 3), M0 = 28.9644 kg/kmol
(section 1.2.4, page 9), and the 0/11/20 km geopotential boundaries and
-6.5/0 K per km gradients (Table 4, page 3). Use R = R*/M0 without rounding.
The NASA PDF's appended 2015 errata identify incorrect R* and radius powers
of ten in Table 2; the implementation uses the corrected values from the body
text, as the errata direct. Those errata do not resolve the pressure checkpoint.

Temperature uses equation (23); pressure uses (33a)/(33b); density uses the
perfect-gas relation, equation (42); sound speed uses (50). Geometric input
is converted with H = r0*Z/(r0+Z), equation (18). The two explicitly named API
entry points avoid silently treating geometric and geopotential height as equal.
`isa_at_geopotential_altitude` accepts finite **H in [0, 20000] m inclusive**.
`isa_at_geometric_altitude` accepts finite **Z in [0, 20000] m inclusive**, checked
before conversion. Thus Z = 20000 maps to H = 19937.272279 m; H = 20000 is a
separate endpoint (approximately Z = 20063.124 m). There is no unnamed altitude
API or implicit choice. Negative, above-limit and non-finite heights are errors.

Mach number is defined by convention as airspeed divided by the local speed
of sound: Mach = V / a. Dynamic pressure = 0.5*density*airspeed^2 follows
docs/CONVENTIONS.md. Their hand-constructed tests are synthetic mathematical
cases, not measurements.
